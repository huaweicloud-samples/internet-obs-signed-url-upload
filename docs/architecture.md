# 架构说明

## 总体架构

本实践演示「服务端只签发授权、文件由浏览器直传对象存储」的链路：Web 页面向接口请求一个有时效的 PUT 授权 URL，再用该 URL 把图片字节直接写入 OBS。函数全程不接触文件体，也不持有长期密钥。

```
                         ┌──────────────────┐
                         │    用户浏览器    │
                         │  选择 JPEG 图片  │
                         └─────────┬────────┘
                                   │ ① GET /upload-url
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│                    APIG 专享版（公网入口）                         │
│       GET /upload-url · 跨域已开启 · 同步调用函数                  │
└───────────────────────────────┬────────────────────────────────────┘
                                │
                                ▼
┌────────────────────────────────────────────────────────────────────┐
│          FunctionGraph  issue-upload-url（Node.js 18）             │
│   读取委托下发的临时凭据 → 生成对象 PUT 授权 URL（15 分钟）        │
│   只返回 uploadURL + photoFilename，不接收任何文件字节             │
└───────────┬─────────────────────────────────────┬──────────────────┘
            │ 返回 JSON                           │ 读取临时凭据
            ▼                                     ▼
┌────────────────────────────┐    ┌──────────────────────────────────┐
│ 浏览器用授权 URL 直传      │    │ IAM 云服务委托                   │
│ ② PUT 文件字节 → OBS       │    │ 临时 AK / SK / SecurityToken     │
└──────────────┬─────────────┘    └──────────────────────────────────┘
               │ ② https://<bucket>.obs.<region>/<key>
               ▼
┌────────────────────────────────────────────────────────────────────┐
│               OBS 私有桶（跨域规则允许 PUT）                       │
│  对象名 <random>.jpg · 桶保持私有 · 函数不接触文件字节             │
└────────────────────────────────────────────────────────────────────┘
```

## 关键组件

| 组件 | 服务 | 职责 |
|---|---|---|
| 授权接口 | APIG 专享版 | 对外提供 `GET /upload-url`，开启跨域，同步调用函数；API 需显式发布到 `RELEASE` 环境 |
| 签发函数 | FunctionGraph | Node.js 18 运行时；读取委托下发的临时凭据，为随机对象名生成 PUT 授权 URL |
| 凭据来源 | IAM 云服务委托 | 以 `op_svc_cff` 为被委托服务，授予 `OBS OperateAccess`；临时凭据由平台自动轮换，不写入代码或配置 |
| 对象存储 | OBS | 私有桶，配置跨域规则允许浏览器 PUT；桶策略声明账号域内主体可写对象 |
| 网络 | VPC / 子网 / 安全组 | 供 APIG 专享实例使用；函数不挂载 VPC |
| 演示页面 | 静态 HTML | 请求授权 URL 后把所选 JPEG 字节直接 PUT 到 OBS |

## 工作流程

1. 浏览器调用 `GET /upload-url`。
2. APIG 同步调用 FunctionGraph 函数。
3. 函数生成随机对象名（十进制 ID + `.jpg`），用委托下发的临时凭据为该对象计算 PUT 授权 URL。
4. 函数返回 `uploadURL` 与 `photoFilename`，并带上跨域响应头与 `Cache-Control: no-store`。
5. 浏览器以 `PUT` 把文件字节直接发送到 `uploadURL`，请求头 `Content-Type` 必须与签名时使用的一致。
6. OBS 校验签名、有效期与临时凭据标识后写入对象；文件字节不经过函数。

## 安全设计

| 项 | 设计 |
|---|---|
| 凭据 | 由 IAM 云服务委托在运行时下发临时 AK / SK / SecurityToken，平台自动轮换；桶内对象与代码包中不含长期密钥 |
| 授权范围 | 每个 URL 只针对一个具体对象、一个 HTTP 方法（PUT）与一个内容类型生效 |
| 有效期 | 默认 900 秒；签名 URL 中的 `Expires` 是 Unix 秒级绝对时间戳 |
| 桶权限 | 桶保持 `private`，不开启公共写；桶策略只放行账号域内主体 |
| 传输 | 接口与对象上传均使用 HTTPS |
| 跨域 | APIG 侧 `cors = true` 处理接口跨域，OBS 侧 `cors_rule` 处理直传跨域，两者缺一不可 |
| 响应缓存 | 授权 URL 属于一次性凭据，响应显式设置 `Cache-Control: no-store` |

> 本实践面向教学演示，接口未启用访问鉴权。用于生产前，建议在 APIG 上启用认证、把 `cors_allowed_origins` 从通配符改为具体站点，并对接口做限流。

## 配置对应关系

| 配置项 | 位置 | 说明 |
|---|---|---|
| `OBS_BUCKET` | `infra/functions.tf` → `user_data` | 目标桶名 |
| `OBS_ENDPOINT` | `infra/functions.tf` → `user_data` | 区域对象存储端点 |
| `UPLOAD_EXPIRES` | `infra/variables.tf` → `signed_url_expires` | 授权 URL 有效期（秒） |
| `UPLOAD_CONTENT_TYPE` | `infra/variables.tf` → `upload_content_type` | 参与签名的内容类型；修改时须同步 `src/frontend/index.html` |
| `cors_rule` | `infra/storage.tf` | 浏览器直传的跨域规则 |
| `func_graph` | `infra/apig.tf` | 网关到函数的同步调用关系 |
| `enable_public_api` | `infra/variables.tf` | 是否创建网关实例与公网入口，默认 `true` |

## 轻量验证档拓扑

把 `enable_public_api` 设为 `false` 时，网关实例、分组、API、发布动作与 VPC / 子网 / 安全组均不创建，其余四个资源保持原样。链路变化只在「谁去触发函数」这一环：

```
                         ┌──────────────────┐
                         │   直接调用函数   │
                         │  （控制台或 CLI）│
                         └─────────┬────────┘
                                   │ ① 触发签发
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│          FunctionGraph  issue-upload-url（Node.js 18）             │
│   读取委托下发的临时凭据 → 生成对象 PUT 授权 URL（15 分钟）        │
└───────────────────────────┬────────────────────────────────────────┘
                            │ ② 返回 uploadURL + photoFilename
                            ▼
┌────────────────────────────────────────────────────────────────────┐
│              客户端用授权 URL 直传（PUT 文件字节）                 │
│              https://<bucket>.obs.<region>/<key>                   │
└───────────────────────────┬────────────────────────────────────────┘
                            │ ③ 签名校验后写入对象
                            ▼
┌────────────────────────────────────────────────────────────────────┐
│               OBS 私有桶（跨域规则允许 PUT）                       │
│  桶保持私有 · 函数不接触文件字节 · 凭据不落盘                      │
└────────────────────────────────────────────────────────────────────┘
```

两档的判废条件相同：只要文件字节不经过函数转发、授权 URL 仍自包含鉴权信息，主题即成立。差别仅在于轻量档没有对外授权接口，因此该档下的验证证据不含公网入口调用，浏览器演示页也无法使用。
